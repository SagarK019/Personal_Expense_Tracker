
# Personal Expense Tracker

A Python-based command-line application that helps users manage their daily expenses, track monthly spending, and maintain budgets.

## Features

- Add new expenses
- View all recorded expenses
- Calculate total expenses
- Search expenses by category
- Generate category-wise spending summaries
- Generate monthly expense reports
- Edit existing expenses
- Delete expenses
- Set monthly budgets
- Monitor monthly budget usage
- Store data permanently using JSON files

## Technologies Used

- Python
- JSON
- File Handling
- CSV is not used in this version

## Project Structure

Personal_Expense_Tracker/
│
├── expense_tracker.py

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python expense_tracker.py

## Data Storage

The application uses JSON files to store expense records and monthly budgets, allowing data to remain available after restarting the program.

## Purpose

This project was developed to practice Python programming, functions, loops, conditional statements, file handling, and data management.
